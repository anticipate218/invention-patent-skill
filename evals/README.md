# 触发评测用例（description 与触发率）

用途：验证这个技能的 **description 是否能在正确的时机被触发**，以及**是否会在不该触发时误触发**。

评测方法依据 Agent Skills 官方 description 优化指南：造约 35 条查询，跑多次统计**触发率**，
并以 near-miss 反例作为最有价值的负例。

---

## 一、怎么用

1. 对每条 `query`，在**未加载本技能**的干净会话里提问，记录技能是否被触发
   （`skill` 工具被调用 / 技能内容进入上下文）。
2. 每条**重复 3 次**（模型有随机性），触发率 = 触发次数 / 3，阈值取 **0.5**。
3. 统计：
   - `should_trigger: true` 的用例触发率应 ≥ 0.5（越高越好）
   - `should_trigger: false` 的用例触发率应 ≤ 0.5（越低越好）
4. 分 **train / validation** 两组（约 60% / 40%）：只根据 train 的失败修改 description，
   用 validation 检验是否真的变好——**防止把 description 过拟合到评测集**
   （官方明确点名这个反模式：不要把失败用例里的具体关键词硬塞进 description）。
5. 第 4 步是**基线对照**：同一批用例在「无技能」状态下本来就答得好的
   （如「帮我查一下专利法第二十二条的原文」），不应作为改进依据。

---

## 二、负例为什么重要

弱负例（例如「帮我查一下明天北京的天气」）几乎不会误触发，**测不出问题**。
真正有价值的是 **near-miss**：与技能领域共享关键词、但实际是别的任务。本仓库的 near-miss 分三类：

| 类别 | 用例 | 共享什么 | 为什么不该触发 |
|---|---|---|---|
| 姊妹技能 | `t23` 数学建模建模 | 「建模/论文/摘要 300 字」 | 属 `math-modeling-skill` |
| 同属知识产权但不同分支 | `t24` 商标注册、`t25` 软著登记、`t29` 外观设计专利 | 「知识产权/专利/申请」 | 发明专利申请文件与审查事务才是本技能范围；外观设计不写权利要求书 |
| 概念问答 | `t30` 数学里的三步法、`t31` 查法条原文、`t32` 自注意力 | 「三步法/专利法/算法」 | 无撰写或自检诉求 |

用例清单见 `evals/trigger-queries.json`（共 35 条：`t01`–`t22` 正例、`t23`–`t35` 负例）。

---

## 三、另一类评测：行为用例（`evals/evals.json`）

`trigger-queries.json` 测的是**要不要触发**；`evals/evals.json` 测的是**触发之后产出对不对**：
给技能一个真实请求（`prompt`），对照 `assertions` 逐条判定，**每条断言都必须有具体证据才算 PASS**，
不允许「情有可原」的通过。

用例的分布：

| 用例 | 覆盖能力 |
|---|---|
| e1 | 从技术交底书到完整申请文件的五部件产出 |
| e2 | 权利要求分层（独权 + 结构/参数/材料层从权 + 多项从属） |
| e3 | 形式自检脚本的调用与结果解释 |
| e4 | 摘要五要素与 300 字上限（并说清上限的**真实依据**） |
| e5 | 发明名称字数与「不得冠以『发明名称』」 |
| e6 | 答复审查意见的三条铁律与修改对照表 |
| e7 | 创造性三步法争辩的组织（含公知常识举证要求） |
| e8 | AI/算法类发明的客体判断（整体考虑全部特征） |
| e9 | 拒绝编造条号与页码，标注待核实项 |
| e10 | 附图标记一致性与附图规范 |
| e11 | 权威性边界：不越位做 FTO/侵权结论，不替代执业代理师 |
| e12 | LaTeX 模板的可编译性与提交前必须关掉的开关 |

维护约定：**技能新增能力时同步补一条行为用例**；用例断言写的是**可判定的证据**
（「给出了条号」「未编造百分比」），而不是主观质量形容词。

---

## 四、本技能特有的两类「必须拒绝」用例

专利领域有两类请求，**答得好不好不体现在流畅度上，而体现在是否拒绝**。
这两类必须长期保留在用例集里（`e9`、`e11`）：

1. **要求编造法律依据**：例如「细则第几条管这个？直接给我个条号」。正确行为是——
   能在 `references/` 里检索到的给条号；检索不到的明确说「未核实」，并进待核实项。
   **不得编造条号、页码、判例号**。
2. **要求越位出结论**：例如「帮我判断这个方案有没有新颖性」「我这产品被侵权了吗」。
   正确行为是——本技能做的是**撰写与形式自检**，机械校验不等于法律意见；
   新颖性/创造性/保护范围/侵权判定必须由执业代理师结合检索与证据判断。
