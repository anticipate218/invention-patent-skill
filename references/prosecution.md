# 审查意见通知书的答复与修改

本文件回答一个问题：**收到审查意见通知书之后，每一步该怎么做、能改什么、不能改什么、话该怎么说**。它面向撰写与答复实务，不重复实体授权条件（见 `references/examination.md`），也不重复流程与法定期限的计算（见 `references/procedure.md`）。

法条出处写在每条规则后的括号里；本次未能从源文件核实的事项集中在 §8。全文示例均为自造案情（如"一种基于图像识别的传送带异物检测方法"），不含任何真实专利号、申请号、申请人或案号。

> 操作顺序建议：**先看通知书类型与期限（§1）→ 再定答复骨架（§2）→ 用三条铁律筛一遍拟修改内容（§3）→ 需要争创造性时套用 §4 模板 → 用 §5 对照表核对意见是否答全 → 交件前过 §7 清单**。

## §1 审查意见通知书类型与流程位置

### 1.1 通知书种类与所处阶段

| 文件 | 所处阶段 | 内容特征 | 依据 |
| --- | --- | --- | --- |
| 补正通知书 | 初步审查（或形式审查） | 指明申请文件存在的缺陷、说明理由、同时指定答复期限 | 《专利审查指南》第一部分第一章（初步审查的通知书规定） |
| 审查意见通知书（初步审查阶段） | 初步审查 | 指明专利申请存在的**实质性缺陷**，说明理由，同时指定答复期限 | 同上 |
| 第一次审查意见通知书 | 实质审查 | 由标准表格 + 通知书正文（+ 对比文件复制件）组成；通常是对申请的全面审查结论 | 指南第二部分第八章 4.10、4.10.2 |
| 再次审查意见通知书 | 实质审查（答复之后） | 撰写方式与要求同第一次；针对修改文本或未修改的文本提出意见 | 指南第二部分第八章 4.11.3.2 |
| 分案通知书 | 实质审查 | 明显缺乏单一性时，审查员可发出分案通知书 | 指南第二部分第八章 4.10.2.2 |
| 视为撤回通知书 | 实质审查 | 申请人未在指定期限内答复等情形下发出 | 指南第二部分第八章 6.1.1 项下及初步审查相应规定 |
| 驳回决定 | 实质审查终结 | 包括标准表格与驳回决定正文（案由、驳回的理由、决定三部分） | 指南第二部分第八章 6.1、6.1.3、6.1.4 |
| 授予专利权通知书 + 办理登记手续通知书 | 审查终结、授权 | 两者同时发出；申请人应当在收到之日起**两个月内**办理登记手续（缴纳授权当年年费） | 指南第五部分第八章 1.1.1、1.1.2；《专利法实施细则》第六十条第一款 |
| 视为放弃取得专利权通知书 | 授权后逾期 | 未在规定期限内办理登记手续；发出后满四个月未恢复的作失效处理 | 指南第五部分第八章 1.1.5 |

### 1.2 驳回决定的"时间门槛"（决定答复策略的关键）

- 审查员作出驳回决定前，应当将认定属于《专利法实施细则》第五十九条应予驳回情形的事实、理由和证据通知申请人，并**给申请人至少一次陈述意见和/或修改申请文件的机会**（指南第二部分第八章 6.1.1）。
- 驳回决定**一般应当在第二次审查意见通知书之后**才能作出；但如果申请人在第一次审查意见通知书指定的期限内**未针对通知书指出的可驳回缺陷提出有说服力的意见陈述和/或证据，也未针对该缺陷修改申请文件，或者修改仅是改正了错别字或更换了表述方式而技术方案没有实质上的改变**，审查员**可以直接作出驳回决定**（指南第二部分第八章 6.1.1）。
- 申请人对申请文件进行了修改的，即使修改后的文件仍存在可用已通知过的理由和证据予以驳回的缺陷，也仍应先给申请人再次陈述和/或修改的机会（指南第二部分第八章 6.1.1）。

> **实务结论**：对第一次审查意见通知书的答复**不能只做文字性调整**。敷衍修改会把"一般需要第二次通知书"变成"可以直接驳回"。

### 1.3 期限

| 期限 | 长度 | 依据 |
| --- | --- | --- |
| 指定期限（一般） | **一般为两个月** | 指南第五部分第七章 1.2 |
| 答复第一次审查意见通知书 | **四个月**（实质审查程序） | 指南第二部分第八章 4.10.3；第五部分第七章 1.2 |
| 办理登记手续 | 自收到授予专利权通知书和办理登记手续通知书之日起**两个月内** | 指南第五部分第八章 1.1.2；《专利法实施细则》第六十条第一款 |
| 期限起算 | 全部**指定期限**和部分法定期限自通知和决定的**送达日**起计算 | 指南第五部分第七章 2.1(2) |
| 延长期限 | 可以请求延长指定的答复期限，但**应当在期限届满前提出** | 指南第五部分第七章第 4 节（延长期限请求及其批准） |

### 1.4 通知书正文的撰写要求（用来检查审查员的论述是否合规）

- 审查员**必须根据专利法及其实施细则具体阐述审查意见**；审查意见应当**明确、具体**；在任何情况下都**应当说明理由、明确结论，并引用专利法或专利法实施细则的相关条款**；不应当写入带有个人感情色彩的词语；必要时可提出修改建议，但**修改建议不能作为进一步审查的文本**（指南第二部分第八章 4.10.1）。
- 申请既涉及权利要求书又涉及说明书的，通知书正文应**按重要性顺序**撰写——先独立权利要求，再从属权利要求，最后说明书（及其附图）和说明书摘要（指南第二部分第八章 4.10.2.2）。
- 因不具备新颖性或创造性而不可能被授予专利权时，必须对**每项权利要求**提出反对意见，先独立权利要求后从属权利要求；权利要求较多或理由相同时可分组评述（指南第二部分第八章 4.10.2.2）。

## §2 答复的基本结构与写作要求

### 2.1 意见陈述书的四段结构

| 段 | 标题建议 | 必须写清的内容 |
| --- | --- | --- |
| 第一段 | 通知书指出的问题 | 逐条摘录审查员指出的缺陷及其所引法条与对比文件（编号、公开日），**不缺项、不改写** |
| 第二段 | 修改内容说明 | 逐处列出"修改前 → 修改后"及**原始记载出处**；附修改对照表或对照页 |
| 第三段 | 逐条答复 | 一条意见一段：事实 → 理由 → 结论，明确"已克服"或"不认同，理由如下" |
| 第四段 | 结论 | 请求在上述修改文本基础上继续审查/授予专利权；列明所附文件清单 |

### 2.2 交件形式要求

- 说明书或者权利要求书的修改部分，应当**按照规定格式提交替换页**（《专利法实施细则》第五十八条）。提交方式有两种：
  - 提交**替换页 + 修改对照表**（适用于修改内容较多的说明书、权利要求书以及所有作了修改的附图）；
  - 提交**替换页 + 在原文复制件上作出修改的对照页**（适用于修改内容较少的说明书和权利要求书）。
  （《专利审查指南》第二部分第八章 5.2.4.1）

### 2.3 写作硬要求

| 要求 | 内容 | 依据 |
| --- | --- | --- |
| 针对缺陷 | 收到审查意见通知书后修改申请文件的，**应当针对通知书指出的缺陷进行修改** | 《专利法实施细则》第五十七条第三款 |
| 不得主动修改 | 在答复审查意见通知书时，**不得再进行主动修改** | 指南第二部分第八章 5.2.1.2 |
| 逐条对应 | 对通知书的每一条意见都要有明确回应；不作笼统的"申请人认为具备创造性"式声明 | 由 4.10.1 对"明确、具体"的要求反向推导（指南第二部分第八章 4.10.1） |
| 不引入新内容 | 答复中提及的技术内容必须能在原始申请文件中找到出处 | 《专利法》第三十三条 |

### 2.4 ❌ / ✅ 对照

| ❌ 答复写法 | 问题 | ✅ 改写 |
| --- | --- | --- |
| "申请人已认真研究审查意见，认为本申请具备新颖性和创造性，请审查员予以授权。" | 无事实、无理由、无结论支撑 | 逐条作答：对比文件 1 未公开特征 X；区别特征 X 带来效果 Y；现有技术无技术启示 |
| "已将权利要求 1 的保护范围作了适当调整。" | 未说明改了什么、根据什么改 | "将权利要求 1 中的'识别单元'限定为'线阵相机与频闪光源同步控制模块'，该表述记载于原说明书第 X 段" |
| 只提交意见陈述书，未提交替换页 | 修改文本无法确定 | 同时提交替换页与修改对照表（《专利法实施细则》第五十八条） |
| 借答复之机把说明书里的另一套方案写成新独立权利要求 | 属不予接受的修改 | 见 §3.2 第 4、5 项 |
| "对比文件 1 与对比文件 2 结合教导了本申请" | 混淆新颖性（单独对比）与创造性 | 新颖性用单独对比；创造性才谈结合与技术启示（指南第二部分第三章 3.1(2)；第二部分第四章 3.2.1.1） |

## §3 修改的三条铁律

### 3.1 铁律一：不得超出原说明书和权利要求书记载的范围

- **《专利法》第三十三条**：申请人可以对其专利申请文件进行修改，但是，对发明和实用新型专利申请文件的修改**不得超出原说明书和权利要求书记载的范围**。
- "原说明书和权利要求书记载的范围"包括：**原说明书和权利要求书文字记载的内容**，以及**根据原说明书和权利要求书文字记载的内容以及说明书附图能直接地、毫无疑义地确定的内容**；**外文文本和优先权文件的内容不能作为判断修改是否超范围的依据**（国际申请原始外文文本除外）。（指南第二部分第八章 5.2.1.1）
- 摘要**不属于原始记载的内容**，不能作为修改申请文件的依据（指南第二部分第二章 2.4）。
- 不允许修改的总原则：凡不符合《专利法》第三十三条的修改均不允许；如果申请的内容通过增加、改变和/或删除其中的一部分，致使所属技术领域的技术人员看到的**信息与原申请记载的信息不同**，而且又不能从原申请记载的信息中**直接地、毫无疑义地确定**，那么这种修改就是不允许的；所述"原申请"**不包括任何优先权文件的内容**（指南第二部分第八章 5.2.3）。
- 指南另列举了不允许的增加（5.2.3.1）与不允许的改变（5.2.3.2）的具体情形与示例。

### 3.2 铁律二：修改应当针对通知书指出的缺陷

- **《专利法实施细则》第五十七条第三款**：申请人在收到审查意见通知书后对专利申请文件进行修改的，**应当针对通知书指出的缺陷进行修改**。
- 主动修改的时机只有两个：**提出实质审查请求时**，以及**收到进入实质审查阶段通知书之日起的 3 个月内**（《专利法实施细则》第五十七条第一款；指南第二部分第八章 5.2.1.2）。
- 时机之外（尤其是答复通知书时）的主动修改不予接受（指南第二部分第八章 5.2.1.2）。

### 3.3 铁律三：五种不予接受的修改（指南第二部分第八章 5.2.1.3）

依《专利法实施细则》第五十七条第三款，申请人答复时的修改应当针对通知书指出的缺陷；下列情形**不予接受**：

| 序号 | 不予接受的修改 | 一句话识别 |
| --- | --- | --- |
| 1 | **主动删除独立权利要求中的技术特征**，扩大了该权利要求请求保护的范围 | 越改越宽 |
| 2 | **主动改变独立权利要求中的技术特征**，导致扩大了请求保护的范围 | 换特征换宽了 |
| 3 | **主动将仅在说明书中记载的与原来要求保护的主题缺乏单一性的技术内容**作为修改后权利要求的主题 | 换了发明 |
| 4 | **主动增加新的独立权利要求**，该独立权利要求限定的技术方案在原权利要求书中未出现过 | 凭空加独权 |
| 5 | **主动增加新的从属权利要求**，该从属权利要求限定的技术方案在原权利要求书中未出现过 | 凭空加从权 |

**处理后果**：审查员应当发出审查意见通知书，说明不接受该修改文本的理由，要求申请人在指定期限内提交符合《专利法实施细则》第五十七条第三款规定的修改文本；同时应当指出，到指定期限届满日为止，申请人提交的修改文本如果仍不符合该规定，审查员将**针对修改前的文本继续审查**，如作出授权或驳回决定（指南第二部分第八章 5.2.1.3）。

> 注意第 3、4、5 项的共同点：它们针对的不是"宽窄"，而是**"改成了另一件发明"**。第 3 项还是单一性缺陷处理规则的延伸（参见 `references/procedure.md` §4 分案）。

### 3.4 允许的修改（答复时可用）

**（a）对权利要求书**（指南第二部分第八章 5.2.2.1）：只要修改后的技术方案**已清楚地记载在原说明书和权利要求书中**，就应当允许。七种情形：

1. 在独立权利要求中**增加技术特征**作进一步限定（克服无新颖性/创造性、缺少必要技术特征、未以说明书为依据或不清楚等缺陷）；
2. **变更独立权利要求中的技术特征**；
3. **变更独立权利要求的类型、主题名称及相应技术特征**；
4. **删除一项或多项权利要求**；
5. 将独立权利要求**相对于最接近的现有技术正确划界**；
6. 修改从属权利要求的**引用部分**（改正引用关系错误）；
7. 修改从属权利要求的**限定部分**。

**数值范围修改的专用规则**：只有在**修改后数值范围的两个端值在原说明书和/或权利要求书中已确实记载**且**修改后的数值范围在原数值范围之内**的前提下才允许。例：原权利要求为 20℃～90℃，说明书或权利要求书还记载了该范围内的 40℃、60℃、80℃，则允许改成 60℃～80℃ 或 60℃～90℃；若原始文件没有记载 30℃、90℃ 这样的端值，则不允许（指南第二部分第八章 5.2.2.1）。

**（b）对说明书及其摘要**（指南第二部分第八章 5.2.2.2）：十一项允许情形——（1）修改发明名称（一般不超过 25 字，必要时不超过 60 字）；（2）修改发明所属技术领域；（3）修改背景技术（允许补入申请日前已公知的现有技术并引证）；（4）修改发明内容中与技术问题有关的内容；（5）修改发明内容中与技术方案有关的内容；（6）修改有益效果（限于本领域技术人员可从原始申请文件**直接、毫无疑义**推断的情形）；（7）修改附图说明（可补充所缺的附图说明）；（8）修改最佳实施方式或者实施例（允许增加的内容一般限于补入**原实施方式或实施例中具体内容的出处**以及**已记载的有益效果数据的标准测量方法**）；（9）修改附图（删除不必要词语注释、使标记与文字一致、增加局部放大图、使每幅图使用一个编号）；（10）修改摘要（含更换摘要附图）；（11）修改明显错误（语法、文字、打印错误，须是本领域技术人员能从说明书整体及上下文看出的唯一正确答案）。

> **重要提示**：5.2.2.2 允许的修改情形中**不包括补入新的技术内容**。(8) 只允许补"出处"和"标准测量方法"，因此**补充新的实验数据、新的实施例一般不能靠修改说明书实现**，只能在意见陈述中作为论证材料使用，且其效果必须能从原始申请文件得出。

### 3.5 三条铁律速查

| 提问 | 通过条件 | 依据 |
| --- | --- | --- |
| 改的内容在原始文件里找得到出处吗？ | 有文字记载，或能直接地、毫无疑义地确定 | 《专利法》第三十三条；指南 5.2.1.1 |
| 改的内容是在解决通知书指出的缺陷吗？ | 是，且不是主动修改 | 《专利法实施细则》第五十七条第三款；指南 5.2.1.2 |
| 改的动作属于五种不予接受之一吗？ | 不属于（未扩大独权范围、未换发明、未凭空加独权/从权） | 指南 5.2.1.3 |

## §4 创造性答复的论证套路

创造性答复的主线是把审查员的结论拆回**三步法**（《专利审查指南》第二部分第四章 3.2.1.1）：确定最接近的现有技术 → 确定区别特征和发明实际解决的技术问题 → 判断是否显而易见。四条可攻击的环节如下。

### 4.1 四条区分线的攻击点

| 区分线 | 攻击点 | 依据 |
| --- | --- | --- |
| A. 最接近现有技术选错 | 审查员选取的对比文件与本发明**技术领域不同**，或未涉及本发明所针对的技术问题，本不能作为三步法第一步的起点 | 指南第二部分第四章 3.2.1.1；第二部分第八章 4.10.2.2 |
| B. 区别特征确定有误 | 审查员**遗漏**了权利要求中的某个技术特征，或把区别特征当作已知特征 | 指南第二部分第八章 4.10.2.2（应完整评述每项权利要求） |
| C. 实际解决的技术问题重新确定 | 应按**区别特征所能达到的技术效果**重新确定"实际解决的技术问题"，而不是照搬说明书或审查员的表述 | 指南第二部分第四章 3.2.1.1 |
| D. 无技术启示 | 现有技术**整体上**未给出将区别特征应用于最接近现有技术以解决其技术问题的启示 | 指南第二部分第四章 3.2.1.1（技术启示的三种情形） |

### 4.2 公知常识的举证责任

- 审查员在审查意见通知书中引用的本领域的**公知常识应当是确凿的**；如果申请人对审查员引用的公知常识**提出异议**，审查员应当能够**提供相应的证据予以证明或说明理由**。
- **将权利要求中对技术问题的解决作出贡献的技术特征认定为公知常识时，通常应当提供证据予以证明**。
（《专利审查指南》第二部分第八章 4.10.2.2）

> 答复动作：凡不同意"该特征属公知常识"的，必须**书面明确提出异议**并要求审查员举证或说明理由。不作异议，等于默认。

### 4.3 避免"事后诸葛亮"

- 判断是否存在技术启示，应以**申请日以前的现有技术**为基础，站在所属技术领域的技术人员的立场；审查中应**避免"事后诸葛亮"**——即不得用本申请公开的技术方案反推现有技术中"本来就有动机"。
（《专利审查指南》第二部分第四章 3.1、6.2）

**识别信号**：审查员用"本领域技术人员容易想到""基于实际需要必然进行改进"一类**不含证据的断言**替代技术启示说明时，即属应质疑的表述。

### 4.4 实验数据与技术效果的支撑

| 主张 | 可以怎么用 | 依据 |
| --- | --- | --- |
| 预料不到的技术效果 | 作为辅助判断因素主张；应说明该效果相对于最接近现有技术的参照系与量级 | 指南第二部分第四章 5.3、6.3 |
| 长期渴望解决的技术难题 | 辅助判断因素 | 指南第二部分第四章 5.1 |
| 克服技术偏见 | 辅助判断因素；需证明现有技术中存在相反教导 | 指南第二部分第四章 5.2 |
| 商业成功 | 辅助判断因素 | 指南第二部分第四章 5.4 |
| 补充实验数据 | ⚠️ 修改说明书时**不允许补入新的技术内容**（5.2.2.2 允许情形中不包括补入新技术内容） | 指南第二部分第八章 5.2.2.2(8) |

> 因此，**有益效果的量化数据必须在原始申请文件中就写好**。这是撰写阶段最重要的预防动作之一。

### 4.5 可套用的分步论证模板句式

以下模板为**自造句式**（指南未发布官方固定套话，见 §8 待核实项 1），按 A→B→C→D 四段取用。

**第 1 段：最接近现有技术的选取**

> 审查员以对比文件 1（公开日：______）作为最接近的现有技术。申请人认为该选取不当。对比文件 1 属于______领域，其所要解决的技术问题是______，而本申请属于______领域，所要解决的技术问题是______。二者**所解决的技术问题不同**，对比文件 1 不能作为评价本申请创造性的起点。（《专利审查指南》第二部分第四章 3.2.1.1）

**第 2 段：区别技术特征的认定**

> 权利要求 1 与对比文件 1 相比，至少存在以下区别技术特征：（1）______；（2）______。审查员在通知书正文中仅认定了区别特征（1），**遗漏了区别特征（2）**。该特征记载于权利要求 1 第______段（"______"），并非对比文件 1 所公开的内容。（《专利审查指南》第二部分第八章 4.10.2.2）

**第 3 段：实际解决的技术问题的重新确定**

> 基于上述区别技术特征，本申请实际解决的技术问题应当重新确定为：______。审查员认定的技术问题"______"是**以对比文件 1 的技术问题代替**（或照搬说明书表述），未考虑区别特征**所能达到的技术效果**，与三步法第二步的要求不符。区别特征（1）取得的效果是______，区别特征（2）取得的效果是______。（《专利审查指南》第二部分第四章 3.2.1.1）

**第 4 段：技术启示的否定**

> 现有技术整体上不存在将上述区别技术特征应用于对比文件 1 以解决上述技术问题的技术启示，理由如下：
> （a）区别特征（1）不属于公知常识。审查员将其认定为公知常识，申请人对此**提出异议**，请审查员提供相应证据予以证明或说明理由；该特征对技术问题的解决作出了贡献，通常应当提供证据予以证明。（《专利审查指南》第二部分第八章 4.10.2.2）
> （b）对比文件 2 中的相应技术手段所起的作用是______，而区别特征（1）在本申请中所起的作用是______，**二者作用不同**，本领域技术人员没有动机将其应用于对比文件 1。（《专利审查指南》第二部分第四章 3.2.1.1 技术启示第（iii）类）
> （c）审查员关于"容易想到"的认定未提供现有技术证据，属于以本申请公开的技术方案反推现有技术的**"事后诸葛亮"**式判断。（《专利审查指南》第二部分第四章 6.2）

**第 5 段：辅助因素（有则写，无则略）**

> 此外，本申请取得了**预料不到的技术效果**：相对于对比文件 1 所公开的方案，本申请的______指标由______提升至______。该效果并非本领域技术人员基于现有技术能够预期。（《专利审查指南》第二部分第四章 5.3、6.3）

### 4.6 完整示例骨架（自造案情）

案情：权利要求 1 为"一种基于图像识别的传送带异物检测方法"，区别特征为"线阵相机行频与传送带速度同步、频闪光源与相机曝光同步"；对比文件 1 公开了"用面阵相机拍摄传送带图像并识别异物"；对比文件 2 公开了"在印刷品检测中使频闪光源与相机曝光同步以减少运动模糊"。

| 段 | 论证内容 |
| --- | --- |
| 区别特征 | 相位同步的行频/曝光时序控制，及其与速度信号的关联 |
| 实际解决的技术问题 | 在传送带高速运行、振动与光照波动条件下稳定获得可比较的差分图像，从而提高检出稳定性（按区别特征所能达到的效果重定） |
| 无技术启示（iii） | 对比文件 2 中同步的作用是消除**印刷品**相对静止扫描时的运动模糊；本申请中的作用是使**相邻帧**在固定相位下可比对以生成差分残差。**作用不同**，不能组合 |
| 辅助因素 | 相对对比文件 1，误报率下降的量化数据（须在原始说明书中已记载） |

## §6 复审与后续程序（简述，详见 `references/procedure.md`）

### 6.1 复审请求

- 复审程序因申请人对**驳回决定**不服而启动，同时也是专利审批程序的延续；合议组一般仅针对驳回决定所依据的理由和证据进行审查，不承担全面审查义务，但可以依职权对驳回决定未提及的**明显实质性缺陷**进行审查（指南第四部分第二章，引言）。
- 本章依据《专利法》第四十一条和《专利法实施细则》第六十五条至第六十八条制定（指南第四部分第二章，引言）。
- **期限**：在收到驳回决定之日起**三个月内**向复审和无效审理部提出复审请求；期限不符合的不予受理（指南第四部分第二章 2.3）。
- **修改限制**：复审请求人对申请文件的修改**应当符合《专利法》第三十三条和《专利法实施细则》第六十六条**的规定；依细则第六十六条，修改**应当仅限于消除驳回决定或者合议组指出的缺陷**。下列情形通常不符合该规定（指南第四部分第二章 4.2）：
  1. 修改后的权利要求相对于驳回决定针对的权利要求**扩大了保护范围**；
  2. 将与驳回决定针对的权利要求所限定的技术方案**缺乏单一性**的技术方案作为修改后的权利要求；
  3. **改变权利要求的类型或者增加权利要求**；
  4. 针对驳回决定指出的缺陷**未涉及**的权利要求或者说明书进行修改（修改明显文字错误，或修改与驳回决定所指出缺陷性质相同的缺陷的情形除外）。
- 上述修改通常**不予接受**，合议组应当在复审通知书中说明该修改文本不能被接受的理由，同时对之前可接受的文本进行审查（指南第四部分第二章 4.2）。
- 前置审查意见的类型包括：复审请求成立同意撤销驳回决定；修改文本克服缺陷同意在修改文本基础上撤销驳回决定；坚持驳回决定（指南第四部分第二章相应规定）。

### 6.2 分案申请

- 一件专利申请包括两项以上发明的，申请人可以主动提出或者依据审查员的审查意见提出分案申请；分案申请应当以原申请为基础提出，类别应当与原申请一致（指南第一部分第一章 5.1.1）。
- **递交时间**：最迟应当在收到专利局对原申请作出授予专利权通知书之日起**两个月期限（即办理登记手续的期限）届满之前**提出；上述期限届满后，或者原申请已被驳回、已撤回、被视为撤回且未恢复权利的，一般不得再提出分案申请（指南第一部分第一章 5.1.1）。
- 对已发出驳回决定的原申请，自收到驳回决定之日起**三个月内**（不论是否提出复审请求）可以提出分案申请；在提出复审请求以后的复审期间、收到复审决定之日起三个月内以及对复审决定不服提起行政诉讼期间，也可以提出分案申请（指南第一部分第一章 5.1.1）。
- 分案申请应当满足的要求（说明书起始部分的说明、原申请号、不得超出原申请记载的范围等）见指南第二部分第六章 3.2。

### 6.3 无效宣告程序中的修改限制

- 无效宣告程序的依据：《专利法》第四十五条、第四十六条、第四十七条、第六十四条和《专利法实施细则》第六十九条至第七十六条（指南第四部分第三章，引言）。
- **修改原则**（指南第四部分第三章 4.6.1）：发明或者实用新型专利文件的修改**仅限于权利要求书**，且应当针对无效宣告理由或者合议组指出的缺陷进行修改——（1）不得改变原权利要求的主题名称；（2）与授权的权利要求相比，不得扩大原专利的保护范围；（3）不得超出原说明书和权利要求书记载的范围；（4）一般不得增加未包含在授权的权利要求书中的技术特征。外观设计专利的专利权人不得修改其专利文件。
- **修改方式**（指南第四部分第三章 4.6.2）：一般限于**权利要求的删除、技术方案的删除、权利要求的进一步限定、明显错误的修正**四种。
- **修改方式的限制**（指南第四部分第三章 4.6.3）：审查决定作出之前，专利权人可以删除权利要求或权利要求中包括的技术方案；**仅在下列三种情形的答复期限内**，可以以删除以外的方式修改权利要求书——（1）针对无效宣告请求书；（2）针对请求人增加的无效宣告理由或者补充的证据；（3）针对合议组引入的请求人未提及的无效宣告理由或者证据。
- **修改文本的提交**（指南第四部分第三章 4.6.4）：应当提交**全文替换页和修改对照表**；同一无效请求审理程序中提交的多个符合规定的修改文本，**以最后一次提交的为准**。

## §7 答复前自查清单

**A. 期限与形式**

- [ ] 确认通知书类型、发出日与送达日，据此计算答复期限（指定期限一般两个月；第一次审查意见通知书四个月）（指南第五部分第七章 1.2、2.1(2)）。
- [ ] 如需延长，已在**期限届满前**提出延长期限请求（指南第五部分第七章第 4 节）。
- [ ] 已提交意见陈述书 + 修改替换页 + 修改对照表/对照页（《专利法实施细则》第五十八条；指南 5.2.4.1）。
- [ ] 请求书/意见陈述书中的发明名称、申请人信息与在案文件一致。

**B. 三条铁律**

- [ ] 每一处修改都能指出**原始记载出处**（说明书段落、权利要求原文、附图中可直接且毫无疑义确定的内容）（《专利法》第三十三条；指南 5.2.1.1）。
- [ ] 摘要没有被当作修改依据（指南第二部分第二章 2.4）；外文文本与优先权文件未被当作超范围判断依据（指南 5.2.1.1）。
- [ ] 每处修改都在**回应通知书指出的缺陷**，没有顺手做主动修改（《专利法实施细则》第五十七条第三款；指南 5.2.1.2）。
- [ ] 不存在五种不予接受的修改：未扩大独权范围、未换发明主题、未凭空增加独权/从权（指南 5.2.1.3）。
- [ ] 数值范围修改满足"端值已记载 + 落在原范围内"（指南 5.2.2.1）。
- [ ] 没有借答复补入新的技术内容、新实施例或新的有益效果数据（指南 5.2.2.2(8)）。

**C. 意见是否答全**

- [ ] 通知书正文按"先独权、后从权、最后说明书及摘要"的顺序逐条核对，无遗漏（指南第二部分第八章 4.10.2.2）。
- [ ] 每条意见都写明"事实—理由—结论"，并明确是"已克服"还是"不认同"（依指南 4.10.1 的明确、具体要求）。
- [ ] 涉及新颖性的，已检查**单独对比**原则是否被违反（指南第二部分第三章 3.1(2)）。
- [ ] 涉及创造性的，已按 §4 的 A/B/C/D 四条区分线组织；对"公知常识"已**明确书面异议**并要求举证（指南第二部分第八章 4.10.2.2）。
- [ ] 主张预料不到的技术效果时，已给出参照系与量化对比，且数据来源可在原始申请文件中找到（指南第二部分第四章 5.3、6.3）。
- [ ] 涉及客体质疑的，已主张"整体考虑全部特征"，并落到技术问题—技术手段—技术效果（《专利法》第二条第二款；指南第二部分第九章 6.1.2、6.1.3）。
- [ ] 结论段明确了请求（在修改文本基础上继续审查/授权）并列出所附文件清单。

**D. 交件前最后一遍**

- [ ] 修改后的权利要求书内部引用关系正确（从属权利要求只引用在前权利要求，多项从属权利要求以择一方式引用）（《专利法实施细则》第二十五条第二款）。
- [ ] 权利要求书与说明书中的科技术语一致（《专利法实施细则》第二十二条第三款）。
- [ ] 全文无因修改产生的矛盾表述（如说明书仍描述已被删除的技术方案）。
- [ ] 上述 A、B、C 三组中任何一项为"否"时，先解决再交件。
