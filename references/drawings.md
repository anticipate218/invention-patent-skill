# 说明书附图与附图标记

附图不是"配图"，而是说明书的组成部分，且**发明专利申请可以没有附图，实用新型必须有**（《专利审查指南》第二部分第二章 2.3）。附图与说明书文字部分之间的关系是**双向锁死**的：说明书里提到的标记必须在图上出现，图上出现的标记必须在说明书里提到（细则第 21 条第 2 款）。

> 本文件的小节编号（`§1`…`§6`）被 `scripts/check_patent.py` 的输出直接引用（形如「依据：references/drawings.md §2」），**不要改动编号**。
> 说明书结构见 `references/specification.md`；摘要见 `references/format.md` §5。

---

## §1 附图的基本要求与编号

**法定依据：《专利法实施细则》第 21 条第 1 款**——发明的**几幅附图应当按照"图1，图2，……"顺序编号排列**；《专利审查指南》第一部分第一章 4.3。

| 要求 | 具体做法 |
|---|---|
| 编号 | 两幅以上附图用**阿拉伯数字顺序编号**，并**冠以"图"字标注在图的正下方**（图1、图2……），不得跳号、不得重号 |
| 一图多页 | 一幅总体图可以分张绘制；应使每幅图使用一个编号（《专利审查指南》第一部分第一章 5.2.2.2(9) 允许按此修改附图编号） |
| 页码 | 附图作为说明书的组成部分**连续编写页码** |
| 方向 | 竖向使用（图内文字方向与图一致） |
| 绘制 | 用制图工具绘制，线条**均匀清晰、足够深**（缩小到三分之二仍能分辨）；**不得涂改** |
| 比例 | 同一附图中相同部件按相同比例绘制；剖面要画剖面线 |
| 无用的框线 | 不应有无用的框线 |

**必要性规则**：

- **发明专利申请**：用文字足以清楚、完整地描述技术方案时**可以没有附图**，此时「附图说明」可整体省略（见 `references/format.md` §4）。
- **实用新型专利申请必须有附图**。
- **补交附图会重新确定申请日**——所以附图应当在提交时一次到位，不要把"图还没画完"当作可以后补的事。

**❌ 常见错误**：图号从 0 开始；用"图一、图二"中文数字；图号写两张图共用一个编号；把图注写在图的上方。

## §2 附图标记

**法定依据：《专利法实施细则》第 21 条第 2 款**——说明书文字部分中**未提及的附图标记不得在附图中出现**，附图中**未出现的附图标记不得在说明书文字部分中提及**；申请文件中表示**同一组成部分的附图标记应当一致**。《专利审查指南》第一部分第一章 4.3：附图标记应当使用**阿拉伯数字**（另有规定者除外），并与说明书文字部分一致。

规则清单：

1. **标记用阿拉伯数字**，按出现顺序编号（1、2、3……），不要用字母或中文序号。
2. **同一部件全文同一个标记**；不同部件不得共用标记。
3. **标记要放在相应技术名称的后面**，不能脱离部件名单独出现——不得写成"3 通过 4 与 5 连接"。
4. 标记不得作为技术特征的替代：不能写"所述（1）转动连接（2）"。

### 2.1 ★ 加不加括号：**按部件分别判断**

"加括号"不是全文统一的写法，**哪一种写法用在哪一个部件里是有区别的**，这是最容易写错的一处：

| 写在哪个部件 | 括号 | 依据 |
|---|---|---|
| **说明书 · 具体实施方式**（对照附图描述时） | **不加括号**，写在相应技术名称之后 | 《专利审查指南》第二部分第二章 2.2.6 |
| **权利要求书** | **必须加括号**，放在相应技术特征之后 | 《专利法实施细则》第 22 条第 4 款；《专利审查指南》第二部分第二章 3.2.2 |
| **说明书摘要** | **应当加括号** | 《专利审查指南》第二部分第二章 2.4 末段 |
| **说明书 · 附图说明**中列举标记 | **不加括号**（见 §3.1） | 无明文要求加括号；通例不加，指南第一部分第一章 4.3 的范例即写作"图1 …：1—传送带；2—工业相机" |

> **这四行的性质不完全相同**：具体实施方式与权利要求书两条是**明文**（指南 2.2.6 写"不加括号"、细则第 22 条第 4 款写"置于括号内"），摘要一条是**明文**（指南 2.4 末段写"应当加括号"）；**附图说明这一条没有明文**——只是因为没有任何条文要求它加括号，且指南范例写作"1—传送带"，所以按不加处理。如果审查意见对某一种写法提出异议，以通知书和审查员的口径为准。

《专利审查指南》第二部分第二章 2.2.6 的原文口径是：**对照附图描述发明的优选的具体实施方式时，使用的附图标记或者符号应当与附图中所示的一致，并放在相应的技术名称的后面，不加括号**；
紧接着举例说明——对涉及电路连接的说明，可以写成"**电阻 3 通过三极管 4 的集电极与电容 5 相连接**"，**不得写成"3 通过 4 与 5 连接"**。

**❌ 错误示例**

```
【具体实施方式】
所述支架（1）通过销轴（2）与底座（3）铰接。   ← 具体实施方式里不该加括号（指南 2.2.6）
所述支架（5）固定在底座（3）上。               ← 同一"支架"用了两个标记 1/5（细则第 21 条第 2 款）
3 通过 4 与 5 连接。                           ← 标记脱离了技术名称（指南 2.2.6）
```

**✅ 正确示例**

```
【具体实施方式】
所述支架 1 通过销轴 2 与底座 3 铰接，所述底座 3 固定在机架 4 上。

【权利要求书】
2. 根据权利要求 1 所述的装置，其特征在于，所述支架（1）通过销轴（2）与所述底座（3）铰接。
```

> **为什么权利要求必须加括号**：依靠标记理解权利要求，但**附图标记不得解释为对权利要求的限制**（细则第 22 条第 4 款）——即范围由技术特征的文字决定，标记只是辅助阅读。所以**不要靠标记来限定范围**。

> `scripts/check_patent.py` 的"附图标记"检查会比较**说明书正文中出现的标记集合**与**「附图说明」中列出的标记集合**：正文用了却没列 → 判失败；列了却没用 → 只给警告。权利要求中的标记不计入这一比较。

## §3 附图说明与正文标记的一致性

**法定依据：《专利法实施细则》第 20 条第 1 款第（四）项**（说明书有附图的，对各幅附图作简略说明）与**第 21 条第 2 款**（标记一致性）。

### 3.1 「附图说明」怎么写

- **逐幅**说明，格式统一：`图1 是本发明实施例的传送带异物检测系统的整体结构示意图；`
- 每幅图的说明都应写明**图名**，并可点明"是……示意图/流程图/框图/剖面图"。
- **同一幅图不要拆成两条**；多幅图按图 1、图 2……顺序列出，与附图编号一致。
- **附图说明里列标记时不加括号**（标记加括号是正文中的写法；此处无明文要求加括号，见 §2.1 的说明）：

```
附图说明
图1 是本发明实施例的异物检测装置的整体结构示意图：1—传送带；2—工业相机；3—光源；4—剔除机构。
图2 是本发明实施例的检测方法流程图。
```

### 3.2 一致性检查（提交前必须自己过一遍）

| 检查 | 判据 |
|---|---|
| 正文标记 ⊄ 附图说明 | ❌ 失败：正文用了标记却未在附图说明中列出（最常见的形式缺陷） |
| 附图说明 ⊄ 正文 | ⚠️ 警告：列了标记但正文没用到（通常是删改后没同步） |
| 标记 ↔ 部件名 | 同一标记对应的部件名称全文必须一致 |
| 图号 ↔ 附图 | 「附图说明」列出的图号必须在"说明书附图"里都能找到对应图 |

> 机械检查：`python scripts/check_patent.py 草稿.md` 的"附图标记"与"附图"两项覆盖上述第 1、2、4 条。第 3 条需要人工核对。

## §4 附图的形式限制

**法定依据：《专利审查指南》第一部分第一章 4.3。**

| 项目 | 规则 |
|---|---|
| 照片 | **一般不得使用照片**；例外为**金相图、组织细胞图、电泳图谱**等必须用照片表示的情形 |
| 工程蓝图 | **不得使用工程蓝图** |
| 涂改 | 附图上不得涂改 |
| 颜色 | **一般使用黑色墨水绘制**；**必要时可以提交彩色附图**（彩色附图在实践中被允许，但不能用它替代"线条足够深、缩小后仍可分辨"的要求） |
| 文字/注释 | 附图中**除必需的词语外不应当含有其他注释**（细则第 21 条第 3 款）；**词语应当使用中文** |
| 流程图/框图 | **应当作为附图**，并在框内给出必要的文字或符号 |
| 插图 | 说明书**文字部分不得有插图**，图一律放"说明书附图" |

关于**灰度/灰阶**：在《专利法实施细则》与《专利审查指南》中**未找到**针对"灰度图"的专门规定，本文件不作为规则表述（见「待核实项」）。实务上按"黑色墨水 + 线条足够深 + 缩小到三分之二可分辨"的通用要求处理。

**❌ 会被判失败**：附图中直接贴现场照片（非金相/组织细胞/电泳图谱类）；用 AutoCAD 输出的工程蓝图直接提交；图里有大段说明文字标注。

## §5 摘要附图

**法定依据：《专利法实施细则》第 26 条第 2 款**——有附图的专利申请，应当在**请求书中指定**一幅最能说明发明技术特征的说明书附图作为**摘要附图**；《专利审查指南》第一部分第一章 4.5.2、第二部分第二章 2.4。

- **从已有的说明书附图中选**，不能另行新画一幅。
- 选取标准：**最能说明技术方案**的那一幅（通常是整体结构图或主流程图），而不是最好看的那一幅。
- **清晰度**：应当保证在**缩小到 4 厘米 × 6 厘米**时仍能分辨清楚。
- 摘要中出现附图标记时**应加括号**（《专利审查指南》第二部分第二章 2.4）。
- **必须在请求书中指定**；未指定的，审查员可以自行指定。
- 摘要附图属于摘要的一部分：摘要**不具有法律效力**，**不属于原始记载的内容**，**不能作为修改申请文件的依据**，**也不能用于解释权利要求的保护范围**（《专利审查指南》第二部分第二章 2.4）。所以**不要把关键限定只写在摘要里**。

## §6 制图规范与自查表

提交前逐项确认：

- [ ] 图号"图1、图2……"连续、无跳号无重号，且标注在**图的正下方**
- [ ] 「附图说明」按图号逐幅列出，与"说明书附图"中的图一一对应
- [ ] **括号按部件分别写对**：具体实施方式**不加括号**（指南 2.2.6）、权利要求**必须加括号**（细则第 22 条第 4 款）、摘要**应当加括号**（指南 2.4）、附图说明列举标记**不加括号**（无明文，见 §2.1）
- [ ] 每个标记都**跟在相应技术名称之后**，没有出现"3 通过 4 与 5 连接"这类脱离部件名的写法
- [ ] 每个标记在正文与附图中的**部件名称一致**、数字一致
- [ ] 正文用到的标记**全部**在附图说明中列出
- [ ] 附图说明中列出的标记**全部**在正文中被使用（否则删掉或补正文）
- [ ] 无照片（金相图/组织细胞图/电泳图谱除外）、无工程蓝图、无涂改
- [ ] 线条均匀、足够深，缩小到三分之二仍可分辨
- [ ] 图内文字使用中文，除必需词语外无其他注释
- [ ] 流程图、框图已作为附图提交，框内有必要文字或符号
- [ ] 说明书**文字部分**没有插图
- [ ] 已在**请求书**中指定摘要附图，且缩小到 4 cm × 6 cm 仍可分辨
- [ ] 附图竖向、按说明书组成部分连续编页
- [ ] 如无附图：确认"用文字足以清楚完整描述"（发明专利可以无附图；**实用新型必须有附图**），并已整体省略「附图说明」

机械检查：

```bash
python scripts/check_patent.py 草稿.md            # 附图标记一致性 + 图号连续性 + 照片/蓝图
python scripts/check_patent.py 草稿.md --strict   # 警告也当失败
```
